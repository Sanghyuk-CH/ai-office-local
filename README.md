# AI 세션 사옥 · 로컬 테스트

내 맥에서 돌아가는 Claude Code 세션을 사옥 화면에 실제로 띄워 보는 묶음입니다.
Node 18 이상만 있으면 되고, 따로 설치할 패키지는 없습니다.

```
Claude Code ──(훅)──▶ ~/.ai-office/events/<세션>.jsonl ──▶ server.mjs ──▶ 브라우저(office.html)
```

## 1. 훅 등록 (한 번만)

```bash
cd ai-office-local
node install.mjs
```

- `~/.claude/settings.json`에 훅 12개를 추가합니다. 기존 설정은 그대로 두고, 바꾸기 전에 `settings.json.bak-날짜` 백업을 만듭니다.
- 훅 스크립트는 `~/.ai-office/hook.mjs`로 복사됩니다.
- 다시 실행해도 두 번 들어가지 않습니다.

## 2. 서버 켜기

```bash
node server.mjs
```

브라우저에서 http://localhost:4317 을 엽니다. 자료 칸이 자동으로 "status.json 파일"로 잡힙니다.
터미널에는 세션에서 생기는 일이 한 줄씩 찍힙니다.

## 3. Claude Code 켜기

**새 터미널**에서 `claude`를 실행하고 아무 일이나 시켜 보세요. 이미 켜져 있던 세션은 껐다 켜야 훅이 붙습니다.
터미널 여러 개에서 여러 프로젝트를 동시에 돌리면 층이 늘어납니다.

## 무엇이 어떻게 보이나

| Claude Code에서 | 사옥에서 |
|---|---|
| 세션 시작 | 엘리베이터 타고 출근, 휴게실에서 대기 |
| 프롬프트 보냄, 도구 사용 | 자기 책상에서 작업 중 (40분 넘으면 땀) |
| 하위 에이전트 띄움 | 노란 모자 하위 작업자 출근, 팀 앞 회의 자리 |
| 권한 요청, AskUserQuestion, 계획 승인 | 맨 위층 대표실 앞에 줄 서기 |
| 답 끝냄 | 결과 보고(만세), 3분 지나면 휴게실로 |
| API 오류·사용량 한도로 멈춤 | 막힘(땀) |
| 세션 종료 | 퇴근 |

- **층(프로젝트)**: 세션을 연 폴더의 git 저장소 이름. git이 아니면 폴더 이름.
- **섬(팀)**: 그 저장소의 브랜치 이름.
- **세션 이름**: 첫 프롬프트의 첫 줄(`/rename`으로 제목을 붙이면 그 제목).
- 직접 정하고 싶으면: `AI_OFFICE_PROJECT=web AI_OFFICE_GROUP=fe claude`

## 정리

```bash
node server.mjs --clear     # 쌓인 기록 지우기
node install.mjs --uninstall  # 훅 빼기 (다른 훅은 건드리지 않음)
```

## 알아 둘 점

- 기록에는 프롬프트 앞 120자, 실행한 명령 앞 80자, 파일 이름이 들어갑니다. `~/.ai-office`에만 저장되고 밖으로 나가지 않습니다. 서버도 이 컴퓨터(127.0.0.1)에서만 열립니다.
- 훅은 사건마다 node를 한 번 띄웁니다(수십 ms). 도구 한 번 쓸 때마다 이 정도가 더해집니다.
- Claude를 끄면 1~2초 안에 퇴근합니다. 종료 훅이 안 와도(창 닫기, Ctrl+C) 훅이 기록해 둔 Claude 프로세스 번호가 사라졌는지 서버가 1초마다 확인합니다. 번호를 못 찾은 세션만 작업 중 2시간, 대기 8시간 뒤 빠집니다.
- 하루 마감(불 끄기)은 아직 자동으로 하지 않습니다.
